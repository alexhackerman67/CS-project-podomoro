# Lil Timer

A standalone Pomodoro timer. No ChatGPT connection, API keys, installs or build step required.

## Try it locally
Open index.html in your browser.

## Publish on GitHub Pages
1. Sign in to GitHub and create a new public repository named lil-timer. Files in a public repository are visible to everyone.
2. Extract this ZIP on your computer.
3. In the repository, select Add file > Upload files. Upload index.html, .nojekyll (if visible) and README.md directly into the repository root. Do not upload the ZIP itself or an enclosing folder. Commit changes.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch. Select main and / (root), then Save.
6. Wait for publication. The Pages settings will show your website link, normally https://YOUR-USERNAME.github.io/lil-timer/.

The website requires no ChatGPT login. School access still depends on your school's website policies.

## Included features
Draggable tomato timer, keyboard-accessible duration controls, focus and break modes, pause/reset, optional chime, task field, and a daily session count saved in the current browser.
